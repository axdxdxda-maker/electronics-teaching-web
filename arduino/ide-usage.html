📋 第一次寫程式的完整流程

1 開啟新檔案：檔案 → 新增，或使用快捷鍵 Ctrl+N
2 撰寫程式：在編輯區輸入你的Arduino程式碼
3 儲存檔案：Ctrl+S 儲存，選擇檔案名稱和位置
4 驗證程式：點擊 ✅ 按鈕檢查語法錯誤
5 選擇開發板：工具 → 開發板，選擇你的Arduino型號
6 選擇序列埠：工具 → 序列埠，選擇Arduino連接的COM埠
7 上傳程式：點擊 ➡️ 按鈕將程式傳送到Arduino
8 測試結果：觀察Arduino的反應，使用序列監視器查看輸出

⚡ 常用快捷鍵

驗證程式 Ctrl + R
上傳程式 Ctrl + U
新增檔案 Ctrl + N
開啟檔案 Ctrl + O
儲存檔案 Ctrl + S
尋找文字 Ctrl + F
註解/取消註解 Ctrl + /
自動縮排 Ctrl + T

💡 實用小技巧

  • 自動完成：輸入函數名稱時，IDE會自動建議完成
  • 語法高亮：不同顏色代表不同的程式元素，幫助閱讀
  • 錯誤提示：紅色底線表示語法錯誤，滑鼠移過去可看錯誤訊息
  • 範例程式：檔案 → 範例，有豐富的學習範例

⚠️ 常見問題解決

  • 上傳失敗：檢查USB連線、序列埠選擇、開發板型號
  • 編譯錯誤：仔細檢查程式語法，缺少分號或括號
  • 序列監視器無資料：確認鮑率設定是否與程式一致
  • 程式無反應：檢查電路連接、接腳編號是否正確
