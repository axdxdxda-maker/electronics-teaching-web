🚀 開始你的Arduino之旅

Arduino IDE是開發Arduino程式的必備工具，讓我們一步步完成安裝設定！

📥 下載Arduino IDE

選擇適合你電腦系統的版本下載：

🪟 Windows

支援 Windows 10 及以上版本

下載 Windows 版本

🍎 macOS

支援 macOS 10.15 及以上版本

下載 macOS 版本

🐧 Linux

AppImage 格式，適用所有Linux發行版

下載 Linux 版本
1

💾 下載與安裝

Windows 用戶：

  • 下載完成後，雙擊 .exe 檔案
  • 選擇「我同意授權條款」
  • 選擇安裝路徑（建議使用預設路徑）
  • 等待安裝完成

⚠️ 注意事項

安裝過程中Windows可能會詢問是否要安裝驅動程式，請選擇「是」來安裝Arduino驅動。

2

🔌 連接Arduino開發板

使用USB線將Arduino連接到電腦：

  • 將USB線的B型接頭插入Arduino
  • 將USB線的A型接頭插入電腦
  • Arduino上的電源LED應該會亮起

✅ 連接成功

如果Arduino上的L燈（13號腳位）開始閃爍，表示連接成功！

3

⚙️ 開啟Arduino IDE

第一次啟動IDE的設定步驟：

  • 在桌面或開始選單找到Arduino IDE圖示
  • 雙擊啟動程式
  • 等待IDE載入完成
  • IDE會自動偵測已連接的Arduino板子

💡 小提示

第一次啟動可能需要較長時間，請耐心等待。IDE會自動下載必要的核心程式庫。

4

🎯 選擇開發板

設定正確的Arduino型號：

  • 點擊工具列上的「選擇開發板」下拉選單
  • 選擇你的Arduino型號（例如：Arduino Uno、Arduino Nano等）
  • 選擇正確的序列埠（通常是COM3、COM4等）

🔍 找不到序列埠？

如果沒有顯示序列埠選項，請檢查：

  • USB線是否正確連接
  • 是否已安裝Arduino驅動程式
  • 嘗試更換USB埠
5

✨ 測試安裝

上傳第一個程式來測試是否安裝成功：

  • 開啟範例程式：檔案 → 範例 → 01.Basics → Blink
  • 點擊「上傳」按鈕（右箭頭圖示）
  • 觀察Arduino上的L燈是否開始閃爍

🎉 安裝完成！

如果L燈正常閃爍，恭喜你已經成功安裝Arduino IDE！現在可以開始你的創作之旅了。
