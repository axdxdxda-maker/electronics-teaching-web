🔌 深入了解Arduino Leonardo

Arduino Leonardo是一款基於ATmega32u4微控制器的開發板，具有內建USB通訊功能和豐富的I/O接腳。

數位接腳 (0-13)
可設定為輸入或輸出，讀取或輸出HIGH/LOW信號
類比接腳 (A0-A5)
可讀取0-5V連續電壓值，解析度10位元(0-1023)
PWM接腳 (3,5,6,9,10,11,13)
可輸出模擬類比電壓，用於控制亮度或轉速
電源接腳
提供穩定的3.3V和5V電源給外部元件

📋 Arduino Leonardo 完整接腳說明

數位接腳 (Digital Pins)

接腳範圍：D0 - D13 (共14個)

電壓範圍：0V (LOW) 或 5V (HIGH)

最大電流：每個接腳40mA

功能：

  • D0 (RX)：序列通訊接收
  • D1 (TX)：序列通訊傳送
  • D2 (SDA)：I2C資料線
  • D3 (SCL)：I2C時鐘線
  • D4-D12：一般數位I/O
  • D13：內建LED + SPI時鐘

PWM接腳 (脈波寬度調變)

接腳：D3, D5, D6, D9, D10, D11, D13

輸出範圍：0-255 (對應0-5V)

頻率：約490Hz或980Hz

用途：

  • LED亮度調節
  • 馬達轉速控制
  • 伺服馬達角度控制
  • 音頻信號產生

類比接腳 (Analog Pins)

接腳範圍：A0 - A5, A6 - A11 (共12個)

輸入範圍：0-5V

解析度：10位元 (0-1023)

輸入阻抗：100MΩ

特殊功能：

  • A4 (SDA)：I2C資料線
  • A5 (SCL)：I2C時鐘線
  • 可作為數位I/O使用
  • A6-A11僅能作為類比輸入

電源接腳 (Power Pins)

VIN：外部電源輸入 (7-12V)

5V：5V穩壓輸出 (最大500mA)

3.3V：3.3V穩壓輸出 (最大50mA)

GND：接地點 (0V參考)

IOREF：I/O邏輯電平參考 (5V)

RESET：重置接腳

AREF：類比參考電壓

💻 Arduino Leonardo 實用程式範例

🔗 基本數位I/O控制

// 控制內建LED (接腳13) void setup() { pinMode(13, OUTPUT); // 設定接腳13為輸出 pinMode(2, INPUT_PULLUP); // 設定接腳2為按鈕輸入 } void loop() { if (digitalRead(2) == LOW) { // 按鈕按下 digitalWrite(13, HIGH); // LED亮起 } else { digitalWrite(13, LOW); // LED熄滅 } }

🌈 PWM調光範例

// LED呼吸燈效果 (使用PWM接腳) void setup() { pinMode(9, OUTPUT); // PWM接腳 } void loop() { // 漸亮 for(int brightness = 0; brightness <= 255; brightness++) { analogWrite(9, brightness); delay(5); } // 漸暗 for(int brightness = 255; brightness >= 0; brightness--) { analogWrite(9, brightness); delay(5); } }

📊 類比感測器讀取

// 讀取電位器或感測器 void setup() { Serial.begin(9600); } void loop() { int sensorValue = analogRead(A0); // 讀取A0 float voltage = sensorValue * (5.0 / 1023.0); // 轉換為電壓 Serial.print("感測器讀值: "); Serial.print(sensorValue); Serial.print(", 電壓: "); Serial.println(voltage); delay(500); }

🖱️ USB鍵盤滑鼠模擬

// Leonardo獨有功能：模擬鍵盤/滑鼠 #include "Keyboard.h" #include "Mouse.h" void setup() { Keyboard.begin(); Mouse.begin(); pinMode(2, INPUT_PULLUP); // 按鈕 } void loop() { if (digitalRead(2) == LOW) { Keyboard.print("Hello from Arduino!"); // 輸入文字 delay(1000); } }

💡 點擊任一接腳查看詳細說明

數位接腳 (Digital Pins)

功能：只能輸出或讀取高電位(5V)或低電位(0V)

用途：控制LED燈、讀取按鈕狀態

接腳：0-13 (共14個)

// 數位輸出範例 void setup() { pinMode(13, OUTPUT); // 設定腳位13為輸出 } void loop() { digitalWrite(13, HIGH); // 輸出5V delay(1000); digitalWrite(13, LOW); // 輸出0V delay(1000); }

類比接腳 (Analog Pins)

功能：可讀取0-5V之間的連續電壓值

用途：讀取感測器數值、電位器調節

接腳：A0-A5 (共6個)

解析度：10位元 (0-1023)

// 類比輸入範例 void setup() { Serial.begin(9600); } void loop() { int value = analogRead(A0); // 讀取A0電壓 Serial.println(value); // 顯示數值(0-1023) delay(100); }

PWM接腳 (脈波調變)

功能：可輸出模擬類比的電壓(透過快速開關)

用途：調節LED亮度、控制馬達轉速

接腳：3, 5, 6, 9, 10, 11 (標示~符號)

數值範圍：0-255

// PWM輸出範例 void setup() { pinMode(9, OUTPUT); } void loop() { for(int i=0; i<=255; i++) { analogWrite(9, i); // 輸出PWM值(0-255) delay(10); // LED逐漸變亮 } }

電源接腳 (Power Pins)

5V：提供5V穩定電源

3.3V：提供3.3V穩定電源

GND：接地端(0V參考點)

VIN：外部電源輸入(7-12V)

⚠️ 電源使用注意事項

  • 5V和3.3V總電流不可超過500mA
  • 每個數位接腳最大電流40mA
  • 必須正確連接GND作為電路迴路

💼 實際應用範例

🔴 控制LED燈

使用接腳：數位接腳(如13)

程式：digitalWrite(13, HIGH/LOW)

應用：指示燈、警示燈

🔘 讀取按鈕

使用接腳：數位接腳(如2)

程式：digitalRead(2)

應用：開關控制、選單操作

🌡️ 溫度感測器

使用接腳：類比接腳(如A0)

程式：analogRead(A0)

應用：溫度監控、自動風扇

💡 調光燈具

使用接腳：PWM接腳(如9)

程式：analogWrite(9, 0-255)

應用：亮度調節、氣氛燈

💡 選擇接腳的技巧

  • 簡單開關控制：使用數位接腳
  • 感測器讀取：使用類比接腳
  • 亮度/速度調節：使用PWM接腳
  • 序列通訊：避免使用接腳0和1
  • 內建LED：接腳13已連接LED，適合測試
