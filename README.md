# 電子元件互動教學網頁

本專案提供 10 種常見電子元件的生活化解釋與互動小實驗，適合國小生入門。

- 麵包板、杜邦線、電阻、三色 LED、震動馬達、數碼管、蜂鳴器、二極體、三極體、按鈕

## 專案結構

- 首頁：`index.html`，列出 10 個元件卡片與基本資訊。
- 元件獨立頁：存放於 `components/` 資料夾。
  - 已完成：`components/breadboard.html`（麵包板）

## 使用方式

- 直接以瀏覽器開啟 `index.html` 即可（支援桌機與手機）。
- 右上角可切換深色/淺色主題。
- 在首頁點選元件卡片可進入各自的詳細頁面。

## 麵包板頁（breadboard.html）

- 上、下各兩排為電源軌：點擊任意孔會「整排」高亮。
- 中間分為上下兩塊：每塊中「同一欄的 5 個洞」彼此相通。
- 互動符合題示圖：下方橫排點擊時整排顯示；中間為五孔一組直向相通。

## 教學重點

- 以生活比喻解釋：
  - 麵包板：同排相通像朋友手牽手。
  - 杜邦線：像延長線把兩點連起來。
  - 電阻：水管粗細影響水流，電阻越大燈越暗。
  - 三色 LED：紅綠藍像水彩調色。
  - 震動馬達：像手機震動，可調速度與力度。
  - 數碼管：7 根「小燈條」排出數字。
  - 蜂鳴器：像門鈴，調整音高，可播放 SOS。
  - 二極體：單行道，正向能通，反向不通。
  - 三極體：小電流控制大電流，像遙控器。
  - 按鈕：按住才亮 vs 按一下切換。
